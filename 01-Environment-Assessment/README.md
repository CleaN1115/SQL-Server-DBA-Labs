# SQL Server DBA Lab 01 – Environment Assessment

## Objective

To assess the SQL Server environment and gather important server information used by database administrators before performing maintenance, upgrades, monitoring, or troubleshooting.

---

## Environment

- SQL Server 2019
- SQL Server Management Studio (SSMS)

---

## Tasks Completed

- Identified SQL Server version
- Identified SQL Server edition
- Checked server name
- Checked instance name
- Listed databases
- Reviewed recovery models
- Identified database file locations
- Reviewed SQL Server services

---

## Skills Demonstrated

- SQL Server Administration
- Server Assessment
- T-SQL
- Database Discovery
- System Catalog Views

---

## What I Learned

I performing an environment assessment helps a DBA understand the SQL Server instance before making configuration changes or troubleshooting issues.

---

## Real-World Scenario
As DBA I often perform an environment assessment after joining a new company or inheriting an existing SQL Server environment. Understanding the server configuration helps ensure maintenance tasks are performed safely and efficiently.
